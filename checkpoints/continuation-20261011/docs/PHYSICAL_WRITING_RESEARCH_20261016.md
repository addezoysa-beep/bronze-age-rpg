## Primary references and decisions

- [Fitzwilliam GR.1.1911](https://data.fitzmuseum.cam.ac.uk/id/object/68603): a clay Linear B account tablet, about1400BCE. Supports a long clay record and an administrative example, not a magical English sentence translated from one glyph.
- [Heraklion Linear B page tablet](https://www.heraklionmuseum.gr/en/exhibit/linear-b-page-tablet/): Linear B records an early form of Greek. [Heraklion Linear A clay tablet](https://ca.heraklionmuseum.gr/ca/pawtucket/index.php/Detail/objects/338) explicitly describes Linear A as undeciphered. The former mixed Linear A/B display has been replaced by a clearly named Linear B exemplar; it does not assert Linear A can be read.
- [Met12.181.203](https://www.metmuseum.org/art/collection/search/554341): New Kingdom wooden ink palette, ca1550–1300BCE. Supports a physically distinct Egyptian palette/pigment/reed/sheet teaching arrangement. The objects are authored stylizations, not a reproduction or new archaeological claim about a specific school.
- [Met66.245.5a](https://www.metmuseum.org/art/collection/search/325842): clay cuneiform letter, ca20th–19th centuryBCE; records letters, disputes and commercial administration, with tablets/envelopes/seals. Supports the clay/reed/seal arrangement and everyday written-record context. This earlier object is a material reference, not a claim all game periods coincide.
- [Oracc Sign List A](https://oracc2.museum.upenn.edu/osl/signlist/l0065/o0000087/index.html): includes the Sumerian water reading and many other readings. The lesson explicitly avoids implying one sign equals one meaning for every language/period. A guessed older ePSD index URL did not load; this actual sign-list record supplied the relevant evidence instead.
- [Met Alphabet Origins](https://www.metmuseum.org/exhibitions/listings/2014/assyria-to-iberia/blog/posts/alphabet): Phoenician/Greek alphabets in the first millenniumBCE and earlier alphabetic traditions; [Met Phoenicians](https://www.metmuseum.org/essays/the-phoenicians-1500-300-b-c) gives the Late Bronze/Iron Age context. Phoenician's presence beside palace Linear B is explicitly a compressed chronology in the optional educational discussion, not presented as identical eras. The cedar writing board is an illustrative game prop, not a copied museum object or asserted standard document type.
- Unicode's character identities: [Linear B](https://www.unicode.org/charts/PDF/U10000.pdf), [Phoenician](https://www.unicode.org/charts/PDF/U10900.pdf), [Cuneiform](https://www.unicode.org/charts/PDF/U12000.pdf), [Egyptian](https://www.unicode.org/charts/PDF/U13000.pdf). B008 is a; N035A is the water logogram, distinct from the single N035 ripple's n sound;10900 is ALF and12000 is A. Native tracing choices now display the corresponding named exemplar. No fonts, font outlines, chart image or museum photograph are extracted/distributed. Mesh strokes are original enlarged teaching diagrams, explicitly not facsimiles; source geometry does not establish rendered palaeographic fidelity.
